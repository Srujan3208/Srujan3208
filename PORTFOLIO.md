# Srujan — Portfolio

A cinematic, motion-rich developer portfolio inspired by the NEXUS 2026 reference website.

## Stack
- Static HTML, CSS and JavaScript
- Canvas particle background
- Scroll reveal and magnetic hover interactions
- Responsive layout and reduced-motion support
- Vercel static deployment

## Deployment
This repository is connected to Vercel. The portfolio is served from the repository root.

## Update contact details
Replace the placeholder email `srujan@example.com` in `index.html` with your preferred professional email before publishing.
